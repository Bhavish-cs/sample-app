Sample App – GCP Skill Badge Project

This repository contains a sample cloud-native application created as part of a Google Cloud Skill Badge / Challenge Lab.
The project demonstrates how to containerize a Go application and deploy it using Google Cloud services.

📌 Project Overview

The goal of this project was to:
Build a simple Go application
Containerize it using Docker
Configure deployment using YAML files
Host and test the application on Google Cloud Platform (GCP)
This repository was automatically created during the Skill Badge lab and includes all required configuration and source files used in the challenge.

🛠️ Tech Stack

Language: Go (Golang)
Containerization: Docker
Cloud Platform: Google Cloud Platform (GCP)
Deployment Config: YAML
Version Control: GitHub
